          Meet Hermes

          What an AI agent is, and what Hermes adds.

          Chatbot answers. Agent acts.

          A chatbot replies to you. An agent works toward a goal: it thinks, uses a tool, looks at the result, and repeats until the job is done.

          What is Hermes?

          Hermes Agent is free, open-source software from Nous Research. It runs AI agents for real: it keeps the loop going and gives each agent what it needs for its job.

          Runs agentsKeeps the think, act, observe loop going until the job is done.
          Gives them toolsWeb search, files, code and more. You choose which tools each agent gets.
          MemoryRemembers useful things about you from one chat to the next.
          SkillsSaved how-tos it can reuse, like recipe cards.
          Scheduled jobsDoes tasks on its own, like a briefing every morning at 8:00.
          Messaging appsTalk to it on Telegram, Discord, Slack and more.

          Step 6 of 11, 10 min
          Harden it
          Every failed test becomes a new rule for your agent. Add the rules, then test again.
          
  
            
  
  
            
    
    
  
            
  
            
  
            A prompt is a request, not a lock.
            
  
            
    
            Prompts can’t
              
      
            • Guarantee the same result twice
              • 
      
            • Tell a fact from a guess
              • 
      
            • Tell real information from hidden orders
              • 
      
            • Remember forever in long chats
            
    
            Code can
              
      
            • Block risky tools until a human approves
              • 
      
            • Give each tool only the access it needs
              • 
      
            • Double-check amounts and answers
              • 
      
            • Keep a record of every action and limit the steps
            
  
            
  
            How Hermes enforces it for real
            
  
            In Hermes, these rules aren’t only words in a prompt. They’re settings the agent can’t talk its way out of.
            
  
            
    
            Toolset limitsEach agent gets only the tools its job needs. Forge has no terminal, so it can’t run code.
            
    
            Dangerous-command approvalRisky commands stop and wait for a human to approve. No chat message can switch that off.
            
    
            Step limitsmax_turns caps the steps in one run, so the agent always stops.
            
    
            User allowlistsOn Telegram, Hermes only answers people who are allowlisted or paired.
            
    
            Secret redactionKeys and passwords in tool results become [REDACTED] before the AI sees them.
            
    
            SOUL.mdYour hardening rules go here, on top of the settings. Words and settings together.
            
  
            
  
            A hardened profile’s settings (config.yaml)
            agent:
  max_turns: 8            # step limit: every run stops
approvals:
  mode: manual            # risky commands wait for a human
  deny: ["rm -rf *"]      # never allowed, even if approved
platform_toolsets:
  telegram: [web, todo]   # only the tools this job needs
privacy:
  redact_pii: true        # hide phone numbers from the AI

# Telegram: only these people can talk to the bot (.env)
# TELEGRAM_ALLOWED_USERS=123456789

            Step 8 of 11, 5 min
            Daily automations
            Hermes can do a job on a schedule, without anyone asking.
            
  
            
    
            What’s a cron job?
            
      
            An alarm clock for your agent. At the set time, Hermes wakes the agent up, gives it a task, and sends the result where you want, like Telegram.
            
      
            The schedule is five parts:
            
      
            
        
            0minute
            8hour
            *day
            *month
            *weekday
            
      
            
      
            0 8 * * * means every day at 8:00. A * means “every”.
            
    
            
    
            How a job like Iris’s is made
            
      
            hermes -p h101-assistant cron create "0 8 * * *" \
  "Write a short morning briefing for students." \
  --name "Morning Briefing" --deliver telegram
            
      
            You don’t need to run this. Iris’s jobs are already set up on the workshop’s Hermes.

            Step 10 of 11, 3 min
            Takeaways
            Six things to remember when you build with AI.
            
  
            
    
            Purpose firstKnow who it serves and its one job before any prompt.
            
    
            Agents loopThink, act, observe. Every step is a decision you can check.
            
    
            Humans approve riskAnything that spends, sends or deletes waits for a person.
            
    
            Break it yourselfTest your agent with tricky messages before real users do.
            
    
            A prompt isn’t a lockReal safety lives in settings and code: toolsets, approvals, step limits, allowlists.
            
    
            Protect real dataUse fake data while building. Never paste personal info.

            Read before you start
            Policies and disclaimer
            The short version of the rules for today.
            
  
            
    
            Workshop disclaimer
            An educational demo. Missions, tools and data are made up. AI output can be wrong or unsafe, so verify before you use it. Live AI and Real agents send your messages to the workshop’s Hermes server and the AI model behind it, so never type personal data. Not affiliated with or endorsed by Nous Research or any AI company.
            
    
            Age and accounts
            Each AI tool sets its own minimum age and terms, and some require users to be 18 or older. If you’re under a tool’s age limit, use a different tool, pair up, or follow the projector.
            
    
            Your data
            Lab work stays on this PC. If you pair Telegram, only your pairing code and the username you type are saved. Survey answers go only to the workshop speaker, for attendance and improvement, in line with the Data Privacy Act of 2012 (RA 10173). Never paste real personal data into AI tools.
            
    
            Academic integrity
            Use AI to learn and build, not to pass off its work as yours. Follow your teachers’ rules on AI use.
            
    
            Responsible use
            The tricky tests in Break it are only for checking your own agent. Never use agents to deceive, spam, collect personal data or get around security.
            
    
            AI tool policies
            Every tool you use today has its own rules. Skim them once.
